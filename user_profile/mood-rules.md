# 情绪场景规则

## 天气-音乐映射
- ☀️ 晴天/温暖：轻快、独立流行、City Pop
- 🌧️ 雨天：安静民谣、氛围音乐、后摇（沉浸感最重要）
- ☁️ 阴天：爵士、Lo-fi、低沉R&B
- 🌙 深夜：低音量氛围音乐、钢琴独奏、后摇
- ❄️ 冷天：温暖系、民谣、独立

## 时段-情绪映射
- 早晨 → 轻快积极
- 上午 → 专注宁静
- 下午 → 有节奏但不打扰
- 傍晚 → 放松随意
- 深夜 → 深沉陪伴

## 活动-音乐映射
- 💻 写代码/学习 → 无歌词轻音乐、Lo-fi、后摇、氛围电子
- 🏃 运动 → 电子、摇滚、高能量流行
- 🚗 开车 → 节奏感强的流行、摇滚
- 😴 准备休息 → 安静钢琴、氛围音乐、自然白噪
- 📖 阅读 → 爵士、古典、轻音乐
- 🎮 游戏 → 电子、Hip-Hop

## 心情-音乐映射
- 😊 开心 → 轻快流行、放克、City Pop
- 😢 伤感 → 民谣、后摇、氛围（陪伴感比刻意的快乐重要）
- 😤 烦躁 → 后摇、氛围音乐（帮助平静下来）
- 😴 疲惫 → 轻音乐、钢琴（不用费脑的音乐）
- 🎸 需要能量 → 摇滚、电子、快节奏流行
